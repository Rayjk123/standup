# Working hours, shell and editor

## Hours

I work from Lagos, UTC+1 all year (no daylight saving). Quiet hours are 22:00 to 07:00 local: no Slack
messages, no pings and no review requests in that window.

## Shell

My shell is fish. Commands you hand me to paste must run in fish: `set -x NAME value`, not
`export NAME=value`, and no heredocs.

## Editor

I edit with helix (`hx`). When a step says "open the file", write `hx path/to/file:LINE`.
