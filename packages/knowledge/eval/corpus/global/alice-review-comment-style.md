# alice's review comment style

How alice likes to give and receive review feedback:

- Inline comments carry a prefix: `nit:` for style, `blocking:` for must-fix, `question:` when she wants an explanation
  rather than a change.
- She batches all her comments into one pass instead of trickling them in, and expects the same from others.
- She'd rather a reviewer suggest the code (a suggestion block) than describe the change in prose.
- Descriptions longer than one screen get skimmed; put detail in a linked design note.
