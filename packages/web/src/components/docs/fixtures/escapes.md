# Escapes

\*not emphasis\* and \_not either\_ and \`not code\`.

\# not a heading, \[not a link\](nowhere) and \!\[not an image\](x.png).

A backslash \\ itself, a pipe \| and angle \<brackets\>.

1\. not a list item

\- not a bullet

\+ not a bullet either

Tilde \~\~not struck\~\~, a dollar $5 and 100% done & more.

An entity &copy; &amp; &#35; stays its character.
